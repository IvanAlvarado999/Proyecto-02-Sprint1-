# Proyecto-02-Sprint1-
# Landing Page Comunitaria: Juegos de antes y de ahora

Repositorio oficial para el desarrollo de la landing page del proyecto comunitario enfocado en la comparación de los juegos tradicionales y las dinámicas de entretenimiento digital de las nuevas generaciones, desarrollado en el sector **Gallegos Lara**.

## 📌 Descripción del Proyecto
Este proyecto forma parte de la fase de planificación, análisis y diseño web orientado a la comunidad. A través de entrevistas a residentes de distintas edades (adultos, adultos mayores y niños), se analiza la transformación del juego, el impacto de la tecnología y la percepción de la seguridad en los espacios públicos durante un evento comunitario realizado por el feriado de 9 de Octubre[cite: 1, 2, 3, 4].

## 🛠️ Tecnologías y Estructura
El sitio web está basado en la plantilla **Massively** de HTML5 UP, estructurada y adaptada para cumplir con los estándares de diseño web moderno y responsivo:
- **HTML5 Semántico** para la estructuración del contenido.
- **CSS3 (Flexbox y Grid)** para el diseño de componentes y maquetación de secciones.
- **Diseño Adaptable (Responsive Design)** optimizado para dispositivos móviles y de escritorio.

## 📁 Estructura del Repositorio
- `index.html`: Página principal de la landing page.
- `generic.html` / `elements.html`: Páginas secundarias y componentes reutilizables.
- `assets/`: Archivos de estilos (CSS), scripts (JS) e imágenes de la plantilla.
- `images/`: Archivos multimedia e imágenes recopiladas en el trabajo de campo.
- `docs/`: Carpeta que contiene la documentación formal del proyecto (Informe completo en formato Word).

## 📄 Documentación Académica
La documentación completa del proyecto, que incluye las secciones de **Análisis** (levantamiento de información y perfiles de referencia) y **Planificación** (organización de contenidos y selección de plantilla), se encuentra disponible dentro del repositorio en la carpeta `docs/` o puede consultarse directamente en el informe formal del sprint.
